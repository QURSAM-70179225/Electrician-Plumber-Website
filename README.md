## 📖 About The Project

This is a **custom freelance website** built for an electrician and plumber service business. It's designed to showcase services, build trust with potential customers, and generate leads through a clean, modern, and mobile-friendly interface.

> 💼 **Project Type:** Freelance / Client Work  
> 🎯 **Goal:** Professional online presence for a local trade business

## 🚀 Getting Started

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/QURSAM-70179225/Electrician-Plumber-Website.git
   ```

2. **Navigate into the folder**
   ```bash
   cd Electrician-Plumber-Website
   ```

3. **Open in browser**
   - Simply double-click `index.html`, **or**
   - Use the VS Code **Live Server** extension for hot reload
